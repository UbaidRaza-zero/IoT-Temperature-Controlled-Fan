RESULTS – IoT-BASED TEMPERATURE-CONTROLLED FAN

1. INTRODUCTION

The IoT-Based Temperature-Controlled Fan is designed to automatically regulate fan speed according to the surrounding temperature.

The system uses an ESP32 microcontroller, DHT11 temperature sensor, and L298N motor driver. The ESP32 processes temperature readings and controls the speed of a DC fan using Pulse Width Modulation (PWM).

The system also integrates the Blynk IoT platform, allowing users to monitor temperature and control fan operation remotely through a mobile dashboard.


2. EXPECTED SYSTEM BEHAVIOUR

The fan operates according to predefined temperature thresholds.

- Below 25°C: Fan OFF.
- At 25°C: Fan starts at low speed.
- 25°C – 40°C: Fan speed gradually increases.
- 40°C and above: Maximum commanded speed.

The fan speed is controlled using PWM signals generated by the ESP32.

8. FINAL RESULT

The proposed system integrates temperature sensing, automatic fan-speed regulation, and IoT-based remote monitoring using an ESP32 microcontroller.

The DHT11 sensor provides environmental temperature readings, while the ESP32 processes these readings and generates PWM signals to control the DC fan through the L298N motor driver.

The integration of the Blynk IoT platform provides additional remote monitoring and manual control functionality.

The project aims to demonstrate an intelligent temperature-based fan-control system with IoT connectivity.
